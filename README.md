# AI Starter Kit — ИИ-помощник на компьютере

Стартовый набор для **Claude Code и Codex**: семь специализированных агентов,
три навыка и установщик. Помогает разобраться с окружением, подготовить проект,
проверить команды и результаты, сохранить работу и подключить нужный инструмент.
Автор — [Александр Капранов](https://github.com/iamsashakapranov).

Сам клиент устанавливается отдельно. Набор добавляет инструкции, а не аккаунт,
подписку или доступ к сервисам. Модель и разрешения выбираются в клиенте;
установщик не меняет их и не редактирует существующие глобальные инструкции.

## Что входит

| Агент | Пример задачи |
|---|---|
| [environment-doctor](agents/environment-doctor.md) | «В терминале работает, а в редакторе не запускается. Найди причину» |
| [security-reviewer](agents/security-reviewer.md) | «Объясни, что изменит эта команда и нужны ли ей такие права» |
| [assistant-docs](agents/assistant-docs.md) | «Как устроены навыки и разрешения в моём Claude Code или Codex?» |
| [research](agents/research.md) | «Изучи несколько источников и сравни варианты с доказательствами» |
| [reviewer](agents/reviewer.md) | «Сверь документ, таблицу или план с исходным заданием» |
| [code-reviewer](agents/code-reviewer.md) | «Проверь изменения программы с учётом связанного кода» |
| [workflow-auditor](agents/workflow-auditor.md) | «Проверь инструкции проекта, структуру и ссылки» |

| Навык | Результат |
|---|---|
| [project-bootstrap](skills/project-bootstrap/SKILL.md) | Минимальные инструкции выбранного проекта с сохранением существующих правил |
| [commit](skills/commit/SKILL.md) | Локальный Git-коммит только проверенных изменений текущей задачи |
| [install-mcp](skills/install-mcp/SKILL.md) | Настройка или диагностика конкретного подключения в выбранном клиенте |

Обычную работу выполняет основной помощник. Диагност и проверяющие возвращают
вывод, а разрешённые исправления делает основной помощник. Все роли сразу
запускать не нужно. [Карта выбора](ROUTING.md) объясняет границы и глубину проверки.

Творческих и маркетинговых пакетов в этом выпуске нет.

## Быстрый старт

Нужны уже установленный Claude Code или Codex и **Python 3.11+**, без дополнительных
Python-пакетов. Git нужен только для клонирования; можно распаковать архив набора.

```bash
git clone https://github.com/iamsashakapranov/ai-starter-kit-sashakapranov.git
cd ai-starter-kit-sashakapranov
```

Выберите клиент и сначала посмотрите план:

```bash
# Claude Code
bash install.sh --client claude --dry-run
bash install.sh --client claude

# Codex
bash install.sh --client codex --dry-run
bash install.sh --client codex
```

Для обоих клиентов укажите `--client both`. Без явного выбора установщик ничего
не записывает. Bash-обёртка ищет доступный Python 3.11+. На Windows без Bash
запускайте через установленный Python 3.11+, например:

```powershell
py -3 install.py --client codex --dry-run
py -3 install.py --client codex
```

Инструкции установки проверены по текущему формату клиентов 9 ноября 2026 года.
Для старой версии сначала проверьте поддержку пользовательских агентов.

## Куда устанавливается

| Клиент | Агенты | Навыки | Карта |
|---|---|---|---|
| Claude Code | `~/.claude/agents/*.md` | `~/.claude/skills/` | `~/.claude/ROUTING.md` |
| Codex | `~/.codex/agents/*.toml` | `~/.agents/skills/` | `~/.codex/ROUTING.md` |

Без `--target` учитываются `CLAUDE_CONFIG_DIR` и `CODEX_HOME`, если они заданы;
пользовательские навыки Codex остаются в `~/.agents/skills`.

Для установки в один проект или тестовую папку задайте **корень**, внутри которого
появятся `.claude`, `.codex` и/или `.agents`:

```bash
bash install.sh --client both --target /absolute/path/to/project --dry-run
bash install.sh --client both --target /absolute/path/to/project
```

С явным `--target` переменные путей клиентов игнорируются. Это отличается от
прежнего Claude-only установщика, где `--target` означал сам каталог конфигурации.
Для Codex проект должен быть доверенным в клиенте; установщик не меняет доверие.
Путь назначения должен быть физическим, без символических ссылок: например,
на macOS `/private/tmp/...`, а не `/tmp/...`.

Исходники ролей хранятся только в `agents/*.md`. Для Claude они копируются,
для Codex из них создаются TOML с `name`, `description`, `developer_instructions`.
Claude-модели и названия инструментов не переносятся в настройки Codex.
Ролевой запрет правок — инструкция поведения, а не отдельная песочница:
фактические права задаёт родительская сессия клиента.

## Обновление существующей установки

Одинаковые файлы пропускаются. Отличающийся файл или конфликт типа останавливает
установку **до записи во все выбранные клиенты**. После просмотра различий
можно явно разрешить замену:

```bash
bash install.sh --client both --replace --dry-run
bash install.sh --client both --replace
```

Прежние файлы сохраняются в `.starter-kit-backups` внутри корня установки
(по умолчанию домашняя папка), с отдельными путями `claude/`, `codex/`, `agents/`.
Установщик печатает точный путь. Для возврата восстановите нужный прежний файл
из копии в исходное место, предварительно сохранив более поздние изменения.

Пользовательские файлы и старые пакеты не удаляются. В частности, прежний
`anthropic-docs` и творческие инструменты могут остаться в личной установке.
Удаляйте их отдельно, только убедившись, что это ненужные копии старого набора.
Автоматической отправки на GitHub, копирования секретов или подключения MCP нет.

## Первые задачи

Начните новую сессию выбранного клиента в рабочем проекте.

1. «Используй environment-doctor: проверь готовность этой папки к моей задаче.
   Только диагностика». Назовите задачу и наблюдаемую проблему, если она есть.
2. «Используй project-bootstrap: подготовь эту папку к работе с Codex и Claude Code,
   сохрани существующие инструкции». Это уже разрешает локальную правку инструкций.
3. «Используй reviewer: сверь этот результат с исходным заданием».

Навык можно выбрать по имени в интерфейсе; в Claude Code используется
`/project-bootstrap`, в Codex — `$project-bootstrap`. Если роль или навык не видны,
проверьте путь, область установки и версию, затем перечитайте инструкции клиента.
Не проверяйте установку командой `commit`: она создаёт настоящий коммит.

Карта `ROUTING.md` необязательна для обнаружения ролей. Её можно прочитать по запросу
или сослаться на неё из своих инструкций. Для Claude используется `@путь/ROUTING.md`;
для Codex — обычное указание в `AGENTS.md` читать карту по соответствующей задаче.
Установщик эти пользовательские файлы не перезаписывает.

## Проверка пакета

```bash
bash tests/install.sh
```

Тесты используют отдельные временные папки: проверяют установку, конфликты,
резервные копии, повторный запуск, формат Codex и сохранение чужих файлов.
Они не проверяют аккаунты и не выполняют модельные запросы. Качество работы
на ваших задачах оценивается отдельно от правильности установки.

Форматы клиентов: [агенты Claude Code](https://code.claude.com/docs/en/sub-agents),
[навыки Claude Code](https://code.claude.com/docs/en/skills),
[агенты Codex](https://learn.chatgpt.com/docs/agent-configuration/subagents),
[навыки Codex](https://learn.chatgpt.com/docs/build-skills).
