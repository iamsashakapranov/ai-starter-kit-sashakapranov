# AI Starter Kit — рабочий набор для ИИ-агента на компьютере

Небольшой набор инструкций для исследования, работы с проектами, проверки
результатов, сохранения изменений и подключения инструментов. Собран
[Александром Капрановым](https://github.com/iamsashakapranov).

Этот выпуск устанавливается в **Claude Code**. Само приложение должно быть
установлено отдельно. Для другого ИИ-клиента можно использовать содержание
инструкций, но подключение ролей и доступные инструменты нужно адаптировать
к этому клиенту: `install.sh` настраивает только каталог Claude Code.

## Состав

Пять агентов и два навыка. Основной помощник выполняет обычную работу сам;
специалисты подключаются для отдельной исследовательской или проверочной задачи.
Все роли одновременно запускать не требуется.

| Агент | Когда полезен |
|---|---|
| [research](agents/research.md) | Собрать несколько источников, изучить документацию или материалы и вернуть вывод с доказательствами |
| [reviewer](agents/reviewer.md) | Сверить документ, таблицу, план или другой результат с заданием и источниками |
| [code-reviewer](agents/code-reviewer.md) | Проверить изменения кода с учётом связанного контекста; нужен для задач разработки |
| [workflow-auditor](agents/workflow-auditor.md) | Найти противоречия в инструкциях проекта, битые ссылки, дубли и проблемы организации работы |
| [anthropic-docs](agents/anthropic-docs.md) | Разобраться в возможностях и настройках Claude Code по актуальной официальной документации |

| Навык | Когда полезен |
|---|---|
| [commit](skills/commit/SKILL.md) | Сохранить проверенные изменения своей задачи локальным Git-коммитом; отправка на сервер требует отдельного разрешения |
| [install-mcp](skills/install-mcp/SKILL.md) | Подключить или диагностировать конкретный MCP-сервер в Claude Code |

[ROUTING.md](ROUTING.md) объясняет выбор инструмента и глубины проверки.
Творческий блок — маркетинг, копирайтинг, дизайн и медиа — удалён из этого выпуска.

## Установка

Для скрипта нужны Bash и обычные файловые утилиты: macOS, Linux или Windows
с WSL. Git нужен для клонирования; архив репозитория также можно распаковать вручную.

```bash
git clone https://github.com/iamsashakapranov/ai-starter-kit-sashakapranov.git
cd ai-starter-kit-sashakapranov
bash install.sh --dry-run
bash install.sh
```

По умолчанию устанавливаются `agents/`, `skills/` и `ROUTING.md` в `~/.claude`.
Посмотреть план для другой папки:

```bash
bash install.sh --target /absolute/path/to/claude-config --dry-run
```

Путь назначения должен быть физическим, без символических ссылок. Например,
на macOS для временной папки используйте `/private/tmp/...` вместо `/tmp/...`.

Одинаковые файлы пропускаются. Если уже есть отличающийся файл, установщик
останавливается до записи. Просмотрите различия; для явной замены используйте:

```bash
bash install.sh --replace --dry-run
bash install.sh --replace
```

Перед заменой установщик сохраняет прежние файлы в резервной папке и сообщает
её путь. Пользовательские файлы и пакеты, которых больше нет в этом наборе,
автоматически не удаляются. Это означает, что обновление репозитория не удалит
старые творческие инструменты из уже настроенного Claude Code. Их удаление
из личной установки — отдельное решение владельца.

Добавьте ссылку на карту в свой `~/.claude/CLAUDE.md`, сохранив остальные правила:

```markdown
## Инструменты стартового набора
@~/.claude/ROUTING.md
```

При использовании другой папки конфигурации укажите фактический путь к карте.
Для загрузки новых ролей начните новую сессию Claude Code.

## Проверка после установки

Попросите: «Покажи доступных агентов стартового набора и проверь небольшой
текст агентом reviewer». Для Git используйте отдельный тестовый проект;
`/commit` создаёт реальный коммит и не подходит для проверки обнаружения навыка.

Для MCP отдельно проверьте наличие CLI `claude` и следуйте инструкции
конкретного сервера. Установка Markdown-файла не означает, что подключение
уже настроено или доступ к сервису работает.

Проверки самого пакета без изменения личной конфигурации:

```bash
bash -n install.sh
bash tests/install.sh
```
