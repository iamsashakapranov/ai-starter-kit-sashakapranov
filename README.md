# AI Starter Kit — стартовый набор для Claude Code

Набор скиллов и агентов, чтобы работать с [Claude Code](https://code.claude.com) эффективно с первого дня — плюс полный учебник на русском. Собран [Александром Капрановым](https://github.com/iamsashakapranov) из реальной практики: всё, что здесь лежит, каждый день работает на живых задачах.

Отдельный упор — на **русские тексты**: копирайтинговые скиллы выжаты из книг и переписаны под рунет (Telegram, VK, Яндекс), с юридикой маркировки рекламы и лимитами русских рекламных кабинетов. Англоязычные аналоги этого не знают.

## Что внутри

### Учебник (`guide/`)

| Файл | Что это |
|---|---|
| [`claude-code-uchebnik-ru.html`](guide/claude-code-uchebnik-ru.html) | Полный учебник по Claude Code на русском: от установки до организации рабочего процесса с базой знаний, IDE и GitHub |
| [`claude-code-terminy-ru.html`](guide/claude-code-terminy-ru.html) | Глоссарий терминов — что означает каждое слово из мира Claude Code |
| [`codex-uchebnik-ru.html`](guide/codex-uchebnik-ru.html) | Учебник по OpenAI Codex на русском для человека без опыта разработки: установка на Windows, работа с документами, права доступа и песочница, безопасность данных |

Третий учебник — про другой инструмент, не про Claude Code. Он здесь потому, что задача у него та же: посадить за ИИ-помощника человека, который не писал кода, и не дать ему навредить себе в первую неделю. Разделы про права доступа, приватность и постановку задачи применимы независимо от того, какой помощник у вас стоит.

Откройте файл в браузере — устанавливать ничего не нужно, всё содержимое внутри страницы (шрифты подтягиваются из сети, без интернета подставятся системные).

### Агенты (`agents/`) — специалисты, которых Claude зовёт сам

| Агент | Что делает |
|---|---|
| `marketer` | **Маркетолог и SMM-стратег — голова для контент-задач.** Решает, что говорить, кому и зачем: стратегия, контент-план, разбор «почему не зашло», бриф на рекламу. Сам текстов не пишет — ставит задачу копирайтинговым скиллам и принимает результат |
| `research` | Глубокое исследование: веб-поиск, чтение документации, изучение кода — не засоряя основной контекст |
| `reviewer` | Ревью любого результата (код, текст, конфиг, план) чистым взглядом со стороны |
| `code-reviewer` | Непредвзятое код-ревью: корректность, читаемость, производительность, безопасность |
| `workflow-auditor` | Аудит базы знаний и процесса: структура, актуальность, дубли, устаревшее, гигиена git |
| `anthropic-docs` | Отвечает на вопросы о Claude Code строго по официальной документации Anthropic |
| `designer` | Дизайнер-исполнитель: от техзадания до готового файла, с самопроверкой в реальном размере |
| `design-critic` | Критик дизайна: смотрит макет, **не зная задания**, и возвращает конкретные правки |

### Скиллы: тексты и продвижение

Русская линейка — руки в связке с агентом `marketer`. Часть из них выжата из книг (источник указан внутри каждого скилла).

| Скилл | Что делает |
|---|---|
| `kp-copy` | Текст коммерческого предложения по русской школе продающего КП: заголовок, оффер, обоснование цены, гарантии, призыв |
| `copywriting-ru` | Текст лендинга и страниц сайта: русские призывы к действию, блоки доверия, коммерческие факторы Яндекса |
| `post-ru` | Пост для Telegram, VK, Threads, Instagram — с каркасами и лимитами каждой площадки |
| `social-ru` | Как вести канал: механика площадок рунета, контент-пиллары, репаковка. **Плюс маркировка рекламы** — erid, ОРД, штрафы по КоАП |
| `hooks-ru` | Крючки и открывашки: заголовок, первые секунды видео, тема письма. С отсевом кликбейта |
| `story-ru` | История в тексте: каркас битов, конфликт, ставки — для кейса, поста-истории, сценария ролика |
| `ad-creative-ru` | Объявления под точные лимиты Яндекс.Директа, VK Рекламы и Telegram Ads |
| `persuasion-ru` | Аудит готового текста на убедительность: какие рычаги влияния работают, каких не хватает, где перегиб |
| `red-pen` | Стилистическая редактура: канцелярит, вода, ритм, точность слова. С предохранителем — в личном тексте голос не выхолащивается |
| `humanize-ru` | Убирает следы машинной генерации. Последний шаг перед публикацией любого текста |
| `voice-ru` | Собирает профиль голоса проекта или автора и следит, чтобы он был в единственном экземпляре |

| Скилл | Что делает |

### Карта связки — [`ROUTING.md`](ROUTING.md)

Главный файл для понимания набора: **кто кого зовёт и в каком порядке**. Задача → инструмент, готовые конвейеры (пост, коммерческое предложение, лендинг, реклама), разрешение спорных случаев, когда подходят двое.

Написан так, чтобы его можно было отдать не только Claude Code, но и любой другой модели вместе с папкой `skills/`.

## Установка

Требуется установленный [Claude Code](https://code.claude.com/docs/en/quickstart).

### Вариант 1 — скрипт (macOS / Linux / WSL)

```bash
git clone https://github.com/iamsashakapranov/ai-starter-kit-sashakapranov.git
cd ai-starter-kit-sashakapranov
bash install.sh
```

### Вариант 2 — вручную

```bash
mkdir -p ~/.claude/skills ~/.claude/agents
cp -R skills/* ~/.claude/skills/
cp -R agents/* ~/.claude/agents/
cp ROUTING.md ~/.claude/
```

### Вариант 3 — попросить Claude

Откройте Claude Code и напишите:

> Склонируй https://github.com/iamsashakapranov/ai-starter-kit-sashakapranov и установи скиллы в ~/.claude/skills, а агентов в ~/.claude/agents

### Подключить карту связки

Чтобы Claude сам понимал, как инструменты работают вместе, добавьте в свой `~/.claude/CLAUDE.md`:

```markdown
## Как связаны инструменты набора
@~/.claude/ROUTING.md
```

## Проверка

Перезапустите Claude Code и напишите в сессии `/commit` — если скилл подхватился, Claude начнёт workflow коммита. Агентов Claude вызывает сам, когда задача подходит под их описание: попросите «найди в вебе…» — уйдёт агент `research`, скажите «разбери, почему пост не зашёл» — включится `marketer`.

## Как это устроено

- **Скилл** — папка с файлом `SKILL.md`: инструкция-процесс, которую Claude подгружает по команде `/имя-скилла` или сам по контексту задачи.
- **Агент** — файл `имя.md` с frontmatter (модель, инструменты) и системным промптом: отдельный специалист со своим контекстным окном.

Подробнее — в [учебнике](guide/claude-code-uchebnik-ru.html) и официальной документации: [Skills](https://code.claude.com/docs/en/skills.md) · [Subagents](https://code.claude.com/docs/en/sub-agents.md).
