# Сохранение работы в Git

Сохрани только изменения текущей задачи. Запрос на просмотр или ревью сам по себе
не разрешает коммит. Явное правило проекта об автоматическом коммите действует
в пределах указанной в нём задачи.

## Перед сохранением

1. Проверь корень репозитория, текущую ветку, рабочее дерево и индекс:
   `git rev-parse --show-toplevel`, `git branch --show-current`,
   `git status --short`, `git diff --stat`, `git diff --cached --stat`.
2. Прочитай правила проекта. Не переключай общую рабочую папку при параллельной
   работе; при необходимости используй отдельную ветку и worktree.
3. Определи свои файлы и участки. Прочитай их diff и выполни подходящие проверки.
   Не добавляй секреты, личные выгрузки, временные результаты и чужие изменения.

## Коммит

- Добавляй конкретные файлы через `git add -- <пути>`, отдельные участки —
  подходящим способом. Не используй `git add -A`, `git add .` или `commit -a`
  для всей рабочей папки.
- Перед коммитом просмотри **весь** `git diff --cached`. Если там есть чужие
  изменения, не снимай их с индекса и не включай в свой коммит. Сохрани свою
  задачу в отдельной рабочей копии либо согласуй разделение с владельцем.
- В изолированном индексе выполни `git commit -m "Краткий результат задачи"`.
  Не добавляй пути к этой команде после частичного staging: Git может взять
  целые файлы из рабочего дерева вместе с невыбранными участками.
- Не меняй автора, настройки подписи или hooks ради обхода ошибки. При сбое
  сообщи фактическую причину; не объявляй работу закоммиченной.

## После сохранения

Проверь `git log -1 --format='%h %s'` и `git status --short`. Сообщи ветку,
хеш, выполненные проверки и оставшиеся изменения.

Push, merge и публикация выполняются только в объёме отдельного разрешения
пользователя; повторно спрашивать уже данное разрешение не нужно. После push
сверь хеш нужной удалённой ветки. Локальный коммит ещё не означает наличие
изменений на GitHub.

Этот навык не копирует `.env`, ключи и другие секреты в облако или резервные
папки. Их хранение — отдельная задача с явно выбранным местом назначения.
