# Иконки macOS: руками, офлайн, без пакетов

Из инструментов нужны: любой Chromium-браузер для рендера (Chrome, Edge, Brave, Яндекс.Браузер — почти у всех уже стоит) и системные `sips` с `iconutil` — они в macOS из коробки.

Проверь путь к браузеру до начала:

```bash
ls "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
   "/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge" \
   "/Applications/Brave Browser.app/Contents/MacOS/Brave Browser" \
   "/Applications/Yandex.app/Contents/MacOS/Yandex" 2>/dev/null
```

Что нашлось — тем и рендери, подставив путь в шаг 2. Нейросеть для иконок не нужна тем более: генератор даёт мыло и кривую геометрию, рука в SVG даёт чистые контуры и правку в один атрибут.

## Правила отрисовки — сначала они, потом команды

Иконка на столе живёт в **48 пикселей** (стандартный размер значков Finder). Всё, что не читается в 48 px, — брак, каким бы красивым ни был исходник 1024×1024.

1. **Рисунок занимает ~90% холста (88–95%).** Знак, сидящий в центре пустого квадрата, в реальном размере превращается в точку. Это правило для одиночных иконок стола; набор под чужую сетку (Material, HIG) — поля по её правилам.
2. **Две толщины линий на весь набор.** На холсте 1024: основной штрих ~44, деталь ~28. Тоньше 22 не рисовать — это меньше пикселя в 48 px, деталь исчезнет.
3. **Никакой диагональной штриховки и мелкого пунктира** — в малых размерах дают муар и грязь.
4. **Одна идея на знак.** Рамка + точки + столбики = каша в 20 пикселях.
5. **Форма несёт смысл:** папка = откроется содержимое, скруглённая плитка = запустится действие. Различается боковым зрением раньше, чем глиф.
6. **Контраст белого знака к подложке ≥ 3:1.** Яркие оранжевые и салатовые фоны проваливают порог — притемняй. Посчитать, не прикидывая:

```bash
python3 -c "
def lum(h):
    r,g,b=[int(h.lstrip('#')[i:i+2],16)/255 for i in (0,2,4)]
    f=lambda c: c/12.92 if c<=0.03928 else ((c+0.055)/1.055)**2.4
    return 0.2126*f(r)+0.7152*f(g)+0.0722*f(b)
a,b=lum('#FFFFFF'),lum('#149152')
print(f'{(max(a,b)+0.05)/(min(a,b)+0.05):.2f}:1')"
```

7. **Цвет уникален внутри набора.** Раздели круг на 8 зон по оттенку (красный, оранжевый, жёлтый, зелёный, бирюзовый, синий, фиолетовый, розовый) — не больше двух иконок на зону, и у тех двух должны различаться силуэты.

**Проверка перед установкой** — только глазами и только в реальном размере:

```bash
sips -z 48 48 icon.png --out preview48.png && open preview48.png
```

## Шаг 1. SVG

Холст 1024×1024. **Сохрани файл как `icon.svg`** — шаг 2 ищет его под этим именем рядом с собой. Заготовка плитки-кнопки:

```xml
<svg xmlns="http://www.w3.org/2000/svg" width="1024" height="1024" viewBox="0 0 1024 1024">
  <rect x="62" y="62" width="900" height="900" rx="202" fill="#149152"/>
  <!-- знак: белые примитивы, центр холста, ~400×400 -->
</svg>
```

Заготовка папки (пропорции системных папок macOS — 95% ширины, 75% высоты) — это полный файл, не фрагмент:

```xml
<svg xmlns="http://www.w3.org/2000/svg" width="1024" height="1024" viewBox="0 0 1024 1024">
<path fill="#1F51B5" d="M 91 168 L 357 168 L 432 269 L 933 269 A 68 68 0 0 1 1001 337
  L 1001 868 A 68 68 0 0 1 933 936 L 91 936 A 68 68 0 0 1 23 868 L 23 236 A 68 68 0 0 1 91 168 Z"/>
<path fill="#2F6FE4" d="M 91 317 L 933 317 A 68 68 0 0 1 1001 385 L 1001 868
  A 68 68 0 0 1 933 936 L 91 936 A 68 68 0 0 1 23 868 L 23 385 A 68 68 0 0 1 91 317 Z"/>
<!-- знак: белые примитивы в рамке ~340×340 с центром (512, 626) -->
</svg>
```

## Шаг 2. SVG → PNG (Chrome headless)

```bash
printf '<style>html,body{margin:0;background:transparent}img{display:block}</style><img src="icon.svg" width="1024" height="1024">' > _r.html
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu \
  --hide-scrollbars --default-background-color=00000000 --force-device-scale-factor=1 \
  --window-size=1024,1024 --screenshot=icon.png "file://$PWD/_r.html"
```

`--default-background-color=00000000` обязателен — без него фон будет белым, а не прозрачным.

## Шаг 3. PNG → .icns

```bash
mkdir -p icon.iconset
for size in 16 32 128 256 512; do
  sips -z $size $size icon.png --out icon.iconset/icon_${size}x${size}.png
  sips -z $((size*2)) $((size*2)) icon.png --out icon.iconset/icon_${size}x${size}@2x.png
done
iconutil -c icns icon.iconset -o icon.icns
```

## Шаг 4. Повесить на файл или папку

```bash
osascript -l JavaScript -e '
ObjC.import("AppKit");
var img = $.NSImage.alloc.initWithContentsOfFile("/полный/путь/icon.icns");
if (img.isNil()) throw "icns не найден — проверь путь";  // без этой строки опечатка в пути МОЛЧА снимет текущую иконку
$.NSWorkspace.sharedWorkspace.setIconForFileOptions(img, "/полный/путь/цель", 0);'
```

**Откат** (вернуть стандартную иконку): тот же вызов с пустой картинкой + снять ресурс:

```bash
osascript -l JavaScript -e 'ObjC.import("AppKit");
$.NSWorkspace.sharedWorkspace.setIconForFileOptions($(), "/путь/цель", 0);'
xattr -d com.apple.ResourceFork "/путь/цель" 2>/dev/null
```

**Уборка после:** `rm -r _r.html icon.iconset` — исходники `icon.svg` и `icon.icns` оставь.

## Грабли — проверено на собственных шишках

| Грабля | Что происходит | Обход |
|---|---|---|
| `qlmanage -t` для проверки | виснет намертво | не использовать; проверка — скриншот стола или рендер PNG |
| Проверка иконки алиаса через `NSWorkspace.iconForFile` | возвращает иконку цели, а не кастомную — ложное «не установилось» | проверять размер ресурса: `stat -f%z 'файл/..namedfork/rsrc'` ≈ размеру .icns |
| Иконка «не применилась» | Finder кэширует | `killall Finder` |
| Расстановка значков стола скриптом | работает только при выключенной автосортировке; шаг сетки меньше ~150 пунктов Finder считает конфликтом и раскидывает по-своему | `defaults read com.apple.finder DesktopViewSettings` → `arrangeBy = none`; шаг колонок от 150 |
| Рисовал под 128 px, поставил — каша | смотрел не в том размере | правило №0: проверка только в 48 px |
| Опечатка в пути к .icns | команда рапортует true и МОЛЧА снимает текущую иконку | строка-предохранитель `if (img.isNil()) throw` уже в сниппете шага 4 — не удаляй её |
| Проверка ресурса у ПАПКИ | у папки ресурс лежит не в ней самой, а в невидимом файле `Icon\r` внутри | `stat -f%z "папка/Icon$'\r'/..namedfork/rsrc"` |
| Фон белый, хотя флаг прозрачности стоит | старый Chrome (примерно 112–117) игнорировал флаг | обнови браузер |
