# MCP в Claude Code

Перед командами проверь `claude --version`, `claude mcp --help` и справку
нужной подкоманды. Источник: [официальная документация](https://code.claude.com/docs/en/mcp).

`local` — подключение для пользователя в текущем проекте; `project` — проектный
`.mcp.json`; `user` — для пользователя в разных проектах. Выбирай область по задаче.

Примеры синтаксиса с демонстрационными адресами, не готовые подключения:

```bash
claude mcp add --transport http --scope local example https://mcp.example.com/mcp
claude mcp add --transport stdio --scope local example -- /absolute/path/to/server
```

После `--` идут команда сервера и её аргументы. Для `npx`/`uvx` бери пакет,
проверенную версию и способ запуска из документации самого сервера.

Статус и авторизация доступны в `/mcp`; используемую конфигурацию и её область
сверяй отдельно. Вывод команд просмотра может содержать секреты — не переноси
его целиком в чат. Изменяй только выбранную запись. При необходимости перечитай
подключения способом, поддерживаемым установленной версией клиента.
