# MCP в Codex

Перед командами проверь `codex --version`, `codex mcp --help` и справку
нужной подкоманды. Источник: [официальная документация OpenAI](https://learn.chatgpt.com/docs/extend/mcp).

Пользовательские подключения хранятся в `config.toml` каталога Codex
(обычно `~/.codex`; путь может задавать `CODEX_HOME`). Проектный вариант —
`.codex/config.toml` доверенного проекта. Сначала определи нужную область.

Примеры синтаксиса с демонстрационными адресами:

```bash
codex mcp add example --url https://mcp.example.com/mcp
codex mcp add example -- /absolute/path/to/server
```

У этих CLI-команд нет Claude-флага `--scope`. Для проектного подключения
следуй документации проектного `config.toml`, сохраняя соседние настройки.
Не подменяй область установки переопределением `CODEX_HOME` на папку проекта.

Для сервера с OAuth используй `codex mcp login <name>` после разрешённого
подключения. Для Bearer-токена проверь поддержку `--bearer-token-env-var`;
передаётся имя уже подготовленной переменной, а не секрет в командной строке.

`codex mcp list` показывает конфигурацию, а `/mcp` в клиенте помогает проверить
активное подключение. Raw/JSON-вывод может включать credentials: фильтруй его
до вывода. Авторизация и один успешный вызов нужного инструмента проверяются
отдельно от наличия записи. Не меняй sandbox, approvals или provider ради MCP.
