# Карта связки: кто кого зовёт

Этот файл — инструкция для ИИ-ассистента (Claude Code или любой другой модели, которой
дали этот набор). Он объясняет, **как инструменты работают вместе**: какой брать под задачу,
в каком порядке выстраивать конвейер и как разрешать спорные случаи, когда подходят двое.

Человеку он тоже полезен — из него видно, что вообще умеет набор.

---

## Главный принцип: голова, руки и чистый взгляд

Инструменты набора делятся на три роли. Их **нельзя совмещать в одном заходе** — именно
разделение даёт качество.

| Роль | Кто | Что делает |
|---|---|---|
| **Голова** | агент `marketer` | решает, что говорить, кому и зачем. Ставит задачу, принимает результат |
| **Руки** | копирайтинговые и дизайн-скиллы | делают конкретный текст или макет по заданию |
| **Чистый взгляд** | агенты `reviewer`, `design-critic`, `code-reviewer` | проверяют результат, **не зная задания** |

Почему так. Тот, кто делал работу, влюблён в неё и не видит своих дыр. Тот, кто ставил
задачу, смотрит на результат и достраивает в голове замысел вместо того, что получилось.
Судить должен третий, у которого нет ни авторства, ни ожиданий.

| Что нужно | Инструмент |

| Пост в Telegram, VK, Threads, Instagram | `post-ru` |

| Крючок, заголовок, первые секунды видео, тема письма | `hooks-ru` |
| История, кейс клиента, сценарий ролика, структура длинного текста | `story-ru` |

## Конвейеры: порядок имеет значение

Правка идёт в три шага, и порядок не случаен. Сначала правится смысл, потом стиль,
в самом конце — следы машины. Обратный порядок бессмыслен: вылизанный абзац, который
потом выкинут при правке структуры, — потерянное время.

```
смысл и структура        →  стиль        →  следы ИИ
(marketer или story-ru)     (red-pen)       (humanize-ru)
```

**Пост в соцсети**
```
marketer (угол, задача)  →  hooks-ru (крючок)  →  post-ru (текст)
                         →  red-pen  →  humanize-ru
```

**Коммерческое предложение**
```
marketer (оффер, рычаг)  →  kp-copy (текст)  →  persuasion-ru (аудит убедительности)
                         →  red-pen  →  humanize-ru
```

**Лендинг**
```
marketer (позиционирование)  →  copywriting-ru (текст страницы)
                             →  red-pen  →  humanize-ru
                             →  art-direction (визуал, если нужен)
```

**Рекламная кампания**
```
marketer (бриф)  →  social-ru (правила площадки и маркировка)
                 →  ad-creative-ru (варианты объявлений)  →  red-pen
```

**История или сценарий ролика**
```
story-ru (каркас, конфликт)  →  hooks-ru (первые секунды)
                             →  red-pen  →  humanize-ru
                             →  video-editing (если это видео)
```

**Любой визуал**
```
art-direction: постановка задачи  →  агент designer (делает)
                                  →  агент design-critic (проверяет вслепую)
                                  →  правки  →  приёмка
```

## Разрешение границ: когда подходят двое

**`marketer` или копирайтинговый скилл?**
Нужно решение и направление («как продвигать», «почему не покупают», «о чём писать») —
`marketer`. Нужен конкретный текст в заданном формате — сразу профильный скилл. Если задача
крупная и непонятно, с чего начать, — начинай с `marketer`, он поставит задачу скиллу сам.

**`red-pen` или `humanize-ru`?**
`red-pen` — текст **криво звучит**: канцелярит, вода, тяжёлые обороты, неточное слово.
`humanize-ru` — текст **пахнет нейросетью**: безликие связки, симметричные перечисления,
дежурная бодрость. Это разные болезни, и лечатся они по очереди, а не вместо друг друга.

**`post-ru` или `social-ru`?**
«Напиши пост» — `post-ru` (конкретный текст). «Как вести канал, что и когда публиковать,
это реклама или нет» — `social-ru` (стратегия и юридика).

**`persuasion-ru` или `red-pen`?**
«Не убеждает, не отвечают» — `persuasion-ru` (какие рычаги влияния работают, каких нет).
«Читается тяжело» — `red-pen` (язык). Текст может быть безупречным стилистически и при
этом ничего не продавать — это разные оси.

**`hooks-ru` или `story-ru`?**
`hooks-ru` — первые секунды, вход в текст. `story-ru` — каркас всего материала целиком.
Крючок без истории обманывает ожидание, история без крючка не доживает до второго абзаца.

**`kp-copy` или `copywriting-ru`?**
Документ-предложение конкретному адресату — `kp-copy`. Страница сайта для многих
читателей — `copywriting-ru`.

## Правила, которые действуют всегда

1. **Текст в публикацию проходит `humanize-ru`.** Это последний шаг любого конвейера.
2. **Профиль голоса читается, а не пересказывается по памяти.** Есть файл голоса — открой
   его. Нет — предложи собрать через `voice-ru`.
3. **Рекламный или бартерный материал проверяется на маркировку** (`social-ru`). В России
   пост без пометки erid — это штраф, а не стилистическая мелочь.
4. **Цифры о рынке — только с источником и годом.** Ни одна модель не должна называть
   рыночные доли по памяти: соседние рынки путаются, и ошибка выходит кратной.
5. **Тактика площадок устаревает за полгода.** Алгоритмы, лимиты и настройки кабинетов
   либо берутся из свежего источника, либо помечаются как требующие проверки.
6. **Результат проверяет тот, кто его не делал.** Для текста — агент `reviewer`, для
   макета — `design-critic`, для кода — `code-reviewer`.

## Как подключить эту карту

**Claude Code.** Положите файл рядом с проектом и сошлитесь на него в своём `CLAUDE.md`:

```markdown
## Как связаны инструменты набора
@~/.claude/ROUTING.md
```

Либо скопируйте содержимое прямо в `CLAUDE.md` — тогда карта будет в контексте каждой сессии.

**Другая модель.** Дайте этот файл целиком в начало диалога вместе с описаниями скиллов
из папки `skills/`. Файлы скиллов самодостаточны: каждый начинается с блока, где написано,
что он делает и по каким словам-триггерам вызывается.
